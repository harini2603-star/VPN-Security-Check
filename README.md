# VPN Security Audit

## Overview

VPN Security Audit is a web-based application that helps users analyze their network security by displaying IP information, VPN status, encryption indicators, and security audit results. The application provides security recommendations and allows users to generate downloadable audit reports.

## Features

* Real-time IP address and network information retrieval
* VPN status detection
* Security audit checklist generation
* DNS leak and encryption status analysis
* Downloadable audit reports
* Interactive and responsive user interface
* Security awareness and best-practice recommendations

## Technologies Used

* HTML5
* CSS3
* JavaScript
* REST API Integration (IPInfo API)

## Functionalities

### Home

* Displays network and VPN information
* Runs security audits
* Generates downloadable audit reports

### About VPNs

* Provides information about VPN technology and its benefits

### Security Tips

* Displays cybersecurity best practices and recommendations

### Security Audit

* Evaluates VPN status
* Checks IP masking status
* Reviews encryption indicators
* Provides security recommendations

### Audit Report

* Generates and downloads audit results in text format

## Sample Audit Checks

* VPN Enabled
* IP Masked
* DNS Leak Test
* Data Encryption Status
* Kill Switch Recommendation
